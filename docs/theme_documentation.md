# KaratCore ERP — Theme & Design Tokens Documentation

Reference documentation for the **KaratCore ERP Design System** tokens, Material 3 configurations, and Swiss Architectural Minimalist color schemes.

---

## 🎨 Color Palette & Tokens (Monochrome Architectural Minimalist)

### Swiss Monochromatic Hierarchy
- **Pitch Black / Carbon 950**: `#000000` / `#09090B` — Deep carbon high-contrast foundation.
- **Architectural Off-White & Pure White**: `#FAFAFA` / `#FFFFFF` — Crisp canvas surfaces & razor-sharp card containers.
- **Hairline Silver Grids**: `#E4E4E7` (Light) / `#27272A` (Dark) — Precision 1px grid borders.
- **Signal Accents**: `#D97706` (Signal Orange) / `#16A34A` (Signal Green) / `#DC2626` (Signal Red) — Used strictly for active alerts & key financial indicators.
